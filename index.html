PetConnect

A social network and playdate matcher for pets, and the Django rebuild of Purrfect Match. Owners share posts and stories, find compatible playmates nearby, and chat in real time.

Highlights: a ranked compatibility score computed in SQL, real-time chat over Ably with per-conversation tokens, a Leaflet / OpenStreetMap map that loads only the visible area, HTMX infinite scroll, a constant query count per page, and a CI-tested Docker deploy on free hosting.

Stack: Django 5.2, HTMX, Alpine.js, Tailwind CSS, PostgreSQL, Ably, Cloudinary.
